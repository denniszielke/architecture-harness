## Evidence rules

- Store evidence in a stable project-approved location; the index contains metadata and links, not large binaries.
- Preserve code, artifact, configuration, dependency, data, environment, time, method, expected result, actual result, and reviewer context.
- A screenshot or generated diagram is not evidence of system behavior by itself.
- Evidence supports only the tested conditions and expires or requires review when its linked input changes.
- Sensitive logs, data, credentials, and security evidence follow access and retention controls and are not copied into public artifacts.
- Presentation claims link to this index and the canonical requirement or decision.
